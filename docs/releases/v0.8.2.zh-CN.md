# 配器手记 v0.8.2

## Windows 可直接下载使用

- Windows x64 ZIP 为 self-contained 发布包：完整解压后可直接运行 `OrchestraNotebook.exe`，无需安装 .NET。
- 第一次启动会自动创建“配器手记”开始菜单快捷方式；之后可通过 Windows 搜索“配器手记”或 `Orchestra Notebook` 启动。
- GitHub 标签发布会自动创建 Release，并附上 Windows 与 macOS ZIP 下载文件。

## MuseScore Studio 4 修复

- MuseScore 4 已不再向 QML 插件提供当前乐谱路径。Windows 宿主现在会从 MuseScore 本地会话记录解析已打开的保存乐谱，选区可以正常建立笔记和小节链接。
