# 配器手记 v0.8.1

这是一个小型命名更新：将原先容易被理解为“只记录华彩”的第五类分析字段统一改为“华彩 / Texture”。

## 变化

- 总谱分析第五部分现在显示为“华彩 / Texture”。
- 模板、筛选器、笔记预览、图片区域以及 Markdown / PDF 导出使用相同名称。
- 这个部分既可以记录独奏式华彩和装饰性跑动，也可以记录持续音型、背景运动与其他织体层。
- 旧笔记完全兼容：内部仍沿用原有 `cadenza` 数据字段，不迁移或删除已有内容、乐器标签和谱例图片。

## 下载

- `Orchestra-Notebook-macOS.zip`：macOS 13 或更高版本。
- `Orchestra-Notebook-Windows-win-x64.zip`：Windows 10/11 x64，自包含 .NET 运行时。

Windows 包需要完整解压后运行 `OrchestraNotebook.exe`。Windows 版已经在 GitHub 的 Windows Server runner 上完成 .NET 8 编译、self-contained 发布、压缩打包和关键文件检查；MuseScore 联动仍建议在实际 Windows 10/11 电脑上进一步验证。
