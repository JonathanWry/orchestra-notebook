# 配器手记 v0.8

第一个可直接下载的 macOS / Windows 双平台版本。

## 主要功能

- Notion 式自由笔记与总谱分析模板。
- Melody、Chord、Bass、Percussion、Cadenza / Pattern 五类构成与筛选。
- 从 MuseScore 选区创建带小节链接的笔记。
- 一条笔记支持多个位置链接与多张华彩谱例。
- 跨乐谱总览、标题/正文/乐谱名搜索和 Description / Mood 精确筛选。
- 乐谱重新定位与整个文件夹扫描修复。
- 导出 Markdown 与 A4 PDF。
- 左侧乐谱库独立滚动。

## 下载

- `Orchestra-Notebook-macOS.zip`：macOS 13 或更高版本。
- `Orchestra-Notebook-Windows-win-x64.zip`：Windows 10/11 x64，自包含 .NET 运行时。

Windows 包需要完整解压后运行 `OrchestraNotebook.exe`。Windows 版已通过 GitHub Windows runner 编译和打包；欢迎反馈不同 Windows 与 MuseScore 4 小版本上的实机结果。

## 数据位置

- macOS：`~/Library/Application Support/Orchestra Notebook/library.json`
- Windows：`%APPDATA%\Orchestra Notebook\library.json`

升级不会覆盖现有资料库。建议在升级前复制一份 `library.json` 作为备份。
